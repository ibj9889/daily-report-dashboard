# 팀장 일일보고 대시보드

카카오톡 팀장 단톡방에 매일 올라오는 일일보고를 사람별, 날짜별, 주/월 단위로 정리해 보여주는 페이지입니다. 회의 때 바로 띄워 쓰도록 만들었습니다.

- 접속 주소: https://ibj9889.github.io/daily-report-dashboard/
- 비밀번호가 있어야 열립니다. 비밀번호는 담당자에게 받으세요.

---

## 1. 동작 방식

```
카톡 대화 내보내기(txt, 담당자 PC)
        |
        v
scripts/build.mjs  ----  한국 시간 변환, 보고/지시/회의록 분류, 특이사항과 일정 추출
        |                AI 요약(private/summaries.json) 합치기
        v
docs/data.enc.js   ----  비밀번호로 암호화한 데이터 (이 파일만 GitHub에 올라감)
        |
        v
GitHub Pages       ----  브라우저에서 비밀번호를 넣으면 그 자리에서 복호화해 화면 표시
```

카톡 원문, 인원 명단, AI 요약 원본, 비밀번호는 담당자 PC의 `private` 폴더에만 있고 GitHub에는 올라가지 않습니다. 저장소가 공개라도 비밀번호 없이는 내용을 볼 수 없습니다.

## 2. 화면 구성

| 화면 | 용도 |
|---|---|
| 회의 브리핑 | 기간(최근 보고일, 이번 주, 지난 주, 이번 달 등)을 고르면 AI 요약, 회의록, 특이사항, 팀 간 협조 요청, 보고에 나온 일정, 근태가 한 화면에 모입니다. 하루를 고르면 일일 요약이, 한 주를 고르면 주간 요약과 일별 한 줄 요약이 나옵니다. 인쇄/PDF 버튼이 있습니다. |
| 일자별 | 맨 위에 AI 일일 요약이 있고, 그 아래로 하루치 일일보고를 사람 순서대로 봅니다. 그날 보고가 없는 사람도 표시합니다. |
| 인원별 | 한 사람의 보고 수, 주별 추이, 자주 다룬 프로젝트, AI 흐름(2주 이내는 일별, 그보다 길면 주별), 받은 협조 요청과 원문을 봅니다. |
| 일간/주간/월간 요약 | AI가 쓴 일일, 주간, 월간 요약과 인원별 집계표입니다. |
| 프로젝트 | LGES, BNYE처럼 여러 팀이 같이 다루는 건을 고르면 팀 구분 없이 언급된 줄을 시간순으로 모아 줍니다. |
| 보고 현황 | 보고일마다 누가 보고를 올렸는지 표로 봅니다. |
| 검색 | 단어로 전체 대화를 찾습니다. |
| 활용 안내 | 회의별 사용법과 데이터 읽을 때 주의할 점입니다. |

주소창 주소가 지금 보는 화면을 가리키므로, 특정 날짜나 사람 화면 링크를 톡방에 그대로 붙여 공유할 수 있습니다.

## 3. 업데이트 방법

### 매일 (데이터만, 약 3분)

1. PC 카카오톡에서 팀장 단톡방을 열고 오른쪽 위 메뉴에서 **대화 내용 > 대화 내보내기**를 눌러 텍스트로 저장합니다. 카톡 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.
2. 저장된 `KakaoTalk_날짜_시각_group.txt` 파일을 이 폴더나 `raw` 폴더에 넣습니다. 예전 파일은 지우지 않아도 됩니다. 겹치는 메시지는 자동으로 한 번만 셉니다.
3. `업데이트.bat`을 더블클릭합니다.
4. 1~2분 뒤 페이지를 새로고침하면 반영됩니다. 오른쪽 위에 갱신 시각이 나옵니다.

### AI 요약까지 갱신할 때

1. 위 1, 2번까지 똑같이 합니다.
2. 이 폴더에서 Claude Code를 열고 `/update-dashboard`를 입력합니다.
3. 새로 생긴 날짜와 주차, 내용이 늘어난 기간의 일일/주간/월간 요약을 다시 쓰고, 데이터를 만들어 GitHub에 올리는 데까지 알아서 진행합니다.

아침 회의 전에 일일 요약까지 보고 싶으면 매일 `/update-dashboard`를 쓰고, 그렇지 않으면 데이터는 매일 `업데이트.bat`으로, 요약은 주 1회 정도 갱신해도 됩니다. 요약이 없는 날은 원문만 보입니다.

요약을 쓰는 기준(형식, 개인정보 제외, 문체)은 `scripts/summary-guide.md`에 있습니다. 요약 방식을 바꾸고 싶으면 이 파일을 고치면 됩니다.

## 4. 다른 사람에게 공유하기

톡방 공지 예시입니다.

```
[팀장 일일보고 대시보드 안내]
매일 올려주시는 일일보고를 사람별, 날짜별, 주간/월간으로 정리한 페이지입니다.
주소: https://ibj9889.github.io/daily-report-dashboard/
비밀번호: (따로 전달)
처음 한 번 비밀번호를 넣으면 그 기기에서는 다시 묻지 않습니다.
회의 때는 '회의 브리핑' 화면을 보시면 됩니다.
```

- 비밀번호는 공지와 분리해서 전달하는 편이 안전합니다.
- 공용 PC에서 본 뒤에는 오른쪽 위 **잠금**을 누르세요.

### 비밀번호 바꾸기

1. `private/password.txt`를 메모장으로 열어 새 비밀번호 한 줄로 바꿉니다. 12자 이상, 영문 대소문자와 숫자를 섞으세요.
2. `업데이트.bat`을 실행합니다.
3. 새 비밀번호를 다시 공유합니다. 기존 기기에 저장된 비밀번호는 자동으로 무효가 되고 다시 입력하라는 화면이 뜹니다.

인원이 바뀌거나 퇴사자가 생기면 비밀번호도 바꾸세요.

## 5. 설정 바꾸기

모두 `private` 폴더에 있고, 고친 뒤 `업데이트.bat`을 실행하면 반영됩니다.

- `members.json`: 대화명과 실명, 팀, 표시 순서를 연결합니다. 대화명이 바뀌거나 새 팀장이 들어오면 여기에 한 줄 추가합니다. `role`이 `leader`이면 그 사람 메시지는 지시사항으로, `member`이면 일일보고 대상으로, `support`이면 보고 대상에서 빠집니다. `"exclude": true`를 붙이면 그 사람 메시지는 대시보드와 AI 요약에서 아예 빠집니다(현재 조상현, 박경수 님). 다른 팀장 보고 안에 그 이름이 나오는 부분은 그 팀장의 보고라서 그대로 남습니다.
- `keywords.json`: 프로젝트 화면에 쓰이는 고객사/과제 이름표입니다. 새 고객사가 생기면 이름과 다른 표기를 추가합니다.
- `settings.json`: 대시보드 제목, 보고일 기준 인원 수 등을 바꿉니다.

### 시간대 관련

카톡 내보내기 파일에는 내보낸 PC의 시간대 기준 시각이 찍힙니다. 빌드할 때 그 PC 시간대를 파일별로 기록해 두고 한국 시간으로 바꿔 표시하므로, 해외 출장 중 내보낸 파일도 날짜가 맞게 나옵니다. 다른 PC에서 내보낸 파일을 가져와 빌드하면 경고가 뜰 수 있는데, 그때는 `settings.json`의 `sourceTimeZone`에 그 PC 시간대(예: `Asia/Seoul`)를 적으세요.

## 6. GitHub Pages 등록 방법

이 저장소는 이미 등록되어 있습니다. 다른 저장소에서 같은 방식으로 페이지를 만들 때 참고하세요.

1. GitHub에서 **New repository**로 저장소를 만듭니다. 무료 계정은 **Public**이어야 Pages를 쓸 수 있습니다.
2. 이 폴더에서 아래 명령으로 올립니다.
   ```
   git init -b main
   git add .
   git commit -m "첫 등록"
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 **Settings > Pages**에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/docs**로 고르고 Save를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 `https://<계정>.github.io/<저장소>/` 주소가 나옵니다.

## 7. 주의할 점

- 공개 저장소에 올라가는 것은 화면 코드와 암호화된 데이터뿐입니다. 그래도 회사 보안 규정상 외부 서비스에 사내 정보를 올리는 것이 허용되는지는 먼저 확인하세요.
- `private` 폴더는 이 PC에만 있습니다. PC가 고장 나면 AI 요약과 설정이 사라지니 가끔 사내 공유 폴더에 복사해 두세요.
- 보고 분류와 특이사항, 일정 추출은 문장 규칙으로 하는 자동 처리라 빠지는 줄이 있을 수 있습니다. 판단은 원문 기준으로 합니다.
- 보고 머리글을 "11/5 - SW2팀 홍길동입니다"처럼 날짜로 시작하고, 특이사항을 "특이사항" 줄 아래에 적으면 자동 분류가 더 정확해집니다.

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 비밀번호가 맞지 않는다고 나옴 | 비밀번호가 바뀌었을 수 있습니다. 담당자에게 확인하세요. |
| 업데이트했는데 예전 내용이 보임 | 1~2분 기다린 뒤 Ctrl+F5로 새로고침합니다. |
| 이름 대신 카톡 대화명이 보임 | `members.json`에 그 대화명이 없습니다. 추가 후 다시 업데이트합니다. |
| 업데이트.bat 실행 중 git push 오류 | GitHub 로그인이 풀린 경우가 많습니다. 명령창에서 `gh auth login`으로 다시 로그인합니다. |
| 날짜가 하루씩 밀려 보임 | 5장 시간대 관련 항목을 확인합니다. |

## 9. 폴더 구조

```
docs/                     GitHub Pages로 공개되는 폴더
  index.html, app.js, style.css
  data.enc.js             암호화된 데이터 (업데이트 때마다 새로 만들어짐)
scripts/
  build.mjs               카톡 txt를 읽어 data.enc.js를 만드는 스크립트
  lib.mjs                 카톡 파싱, 분류, 추출 규칙
  summary-guide.md        AI 요약 작성 기준
.claude/commands/
  update-dashboard.md     Claude Code의 /update-dashboard 명령
업데이트.bat               더블클릭 업데이트
private/                  (GitHub에 안 올라감) 비밀번호, 인원, 키워드, AI 요약
raw/                      (GitHub에 안 올라감) 카톡 txt를 모아 두는 곳
```

필요한 프로그램은 Node.js(18 이상)와 Git, GitHub CLI(gh)입니다.
